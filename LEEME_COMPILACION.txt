RPA CBN — COMPILACIÓN PORTABLE

Copia CREAR_EJECUTABLE.ps1 en la raíz del proyecto, junto a app_gui.py.

1. Instalar/verificar dependencias en el entorno RPA_CBN:

    python -m pip install -r .\requirements_gui.txt
    python -c "import PyInstaller, customtkinter, playwright, PIL; print('OK')"

2. Compilación de diagnóstico:

    powershell -ExecutionPolicy Bypass -File .\CREAR_EJECUTABLE.ps1 -Modo Debug

3. Probar localmente:

    .\dist\RPA_CBN_DEBUG\RPA_CBN_DEBUG.exe

4. Compilación final sin consola:

    powershell -ExecutionPolicy Bypass -File .\CREAR_EJECUTABLE.ps1 -Modo Final

Salidas:

    dist\RPA_CBN\RPA_CBN.exe
    dist\RPA_CBN_Portable.zip

PRUEBA EN OTRA LAPTOP

- Copia RPA_CBN_Portable.zip.
- Descomprímelo en Documentos o Escritorio.
- No lo ejecutes directamente desde dentro del ZIP.
- No copies solamente el EXE.
- La laptop debe tener Microsoft Edge o Google Chrome.
- No requiere Python, Conda, pip ni permisos de administrador.
